# Hi, I'm Tareq

I build small, calm tools for developers and ops people.
Most of them start as something I needed at work and got tidy enough to share.

## Tools

- **[mission-control](https://github.com/tareqy/mission-control)**: a calm Claude Code pane for alarms, merge requests, tasks due and today's calendar.
- **[tack](https://github.com/tareqy/tack)**: a fast, local-first kanban board for macOS (SwiftUI + SwiftData).
- **[frontier-handoff](https://github.com/tareqy/frontier-handoff)**: a framework for preserving and testing prompts and outputs across model generations.
